# BenchmarkDotNet — measured results (18 October 2026)

These are **actual BenchmarkDotNet 0.15.8 results**, not estimates. Raw measurements were generated by the repository's GitHub-hosted benchmark workflow.

- **Run:** https://github.com/PADOALEX/PADO-AlgorithmLab/actions/runs/39146417500
- **Commit measured:** `6e4e166f8198ae6a05f859d9400a8e6c054a657f`
- **Workflow artifacts:** `algorithm-lab-benchmarks` (CSV, Markdown, detailed logs, retention configured for 30 days)
- **Environment:** GitHub-hosted Ubuntu runner (Ubuntu 24.04 image), .NET **10.0.13**, 64-bit RyuJIT; CPU model was not captured in the retained summary. The runner's shared virtualized hardware is not a dedicated benchmarking machine.
- **Benchmark job:** 1 launch; 3 warm-up and 8 measurement iterations; **InvocationCount=1** per iteration, with a newly cloned input during IterationSetup; method timed without educational counters; input check happens after each iteration.
- **Caveat:** short operations in a one-invocation-per-iteration benchmark are susceptible to measurement noise; the table reports the measured run, **not** a guarantee of precision. Repeat on dedicated hardware for stronger conclusions.
